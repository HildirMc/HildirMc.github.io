    Les Parrainages

    Le système de parrainage te permet d’inviter un ami sur Hildir. L’orsqu’il utilise ton code, vous recevez tous les deux 50 Denos. Si ton ami lie son compte Minecraft au Discord d’Hildir, vous gagnezz à nouveau 50 Denos chacun.

    check_circle
    Si tu n’as pas été parrainé, tu peux aussi gagner 50 Denos en liant tes deux comptes. c’est l’occasion d’en profiter !

    Tape /parrainage pour ouvrir le menu de parrainage directement sur le serveur. Tu y retrouveras ton code, ton suivi et la liste de tes filleuls.

    Comment ça fonctionne ? link

    Le serveur te créé un code automatiquement. Il respecte ce format : hildir_<ton_pseudo>_<code_aléatoire>. Tu ne choisis pas ton code, et tu ne peux pas le modifierr. Il est conservé définitivement même si tu changes de pseudo.

    Utiliser le code d’un ami link

    Si tu es un nouveau joueur, avec le code d’un ami, tape /parrainage pour ouvrir le menu. Cliques ensuite sur Utiliser un code pour le renseigner.

    report
    ATTENTION : tu ne disposes que d’une heure après ta première connexion pour rentrer un code. Cette heure s’écoule même si tu te déconnectes. Tu ne peux utiliser qu’un seul code, et tu ne peux pas utiliser ton propre code.

    Si le code que tu as rentré est validé par le système, toi et ton parrain recevrez alors 50 Denos.

    Limite de parrainage link

    Un parrain peut avoir au maximum cinq parrainages acceptés ou en cours sur une période glissante de sept jours.

    Cette période n’est pas remise à zéro un jour précis de la semaine : chaque parrainage cesse progressivement de compter lorsqu’il date de plus de sept jours.

    Une tentative refusée ne réserve pas de place dans cette limite.

    Protection contre les doubles comptes link

    n parrain et son filleul ne peuvent pas recevoir de récompense s’ils ont utilisé la même adresse réseau récemment. Si deux personnes différentes jouent réellement depuis le même foyer, contacte l’équipe avant d’utiliser le code. Un membre du staff pourra étudier la situation et, si elle est légitime, ajouter une exception.

    Conseils link

    • Crée ton code avant d’inviter un ami et envoie-lui le code complet.
    • Demande à ton ami de saisir le code rapidement après sa première connexion.
    • Vérifie chaque caractère du code : une faute de frappe entraînera un refus.
    • Ne partage pas un compte Discord entre plusieurs comptes Minecraft dans le but d’obtenir plusieurs récompenses.
    • Si une récompense reste en attente, reconnecte-toi puis contacte le staff avec ton pseudonyme et l’heure approximative de l’action.
    • Si vous jouez depuis le même foyer, demande une vérification au staff avant d’utiliser le code.

    Questions fréquentes link

    Puis-je modifier mon code ? link

    Non. Il est généré automatiquement lors de sa première consultation et reste associé définitivement à ton compte.

    Mon pseudonyme a changé. Mon ancien code fonctionne-t-il encore ? link

    Oui. Le code initial est conservé et reste valide.

    Puis-je utiliser un code après plus d’une heure ? link

    Non. La période commence à ta toute première connexion au serveur, pas au moment où tu ouvres la commande.

    Puis-je utiliser plusieurs codes ? link

    Non. Un joueur ne peut être associé qu’à un seul parrainage accepté.

    Pourquoi mon parrainage a-t-il été refusé alors que nous sommes deux personnes différentes ? link

    Le système a peut-être détecté une adresse réseau commune dans l’historique. Si vous vivez dans le même foyer, contactez le staff afin que la situation soit vérifiée.

    Le parrain a déjà cinq filleuls. Quand pourra-t-il parrainer à nouveau ? link

    Dès que son plus ancien parrainage comptabilisé aura plus de sept jours. La limite utilise une période glissante.

    Dois-je rester connecté pour recevoir une récompense ? link

    La commande de récompense est exécutée lorsque tu es connecté. Si tu es absent, elle reste en attente jusqu’à ta prochaine connexion.

    Puis-je recevoir plusieurs fois la récompense Discord ? link

    Non. Elle est unique pour le compte Minecraft et pour le compte Discord, même après une dissociation.

    Mon compte est déjà lié, mais je n’ai rien reçu. Que faire ? link

    Attends quelques instants et vérifie que tu es toujours connecté. Si rien ne se passe, contacte le staff en indiquant ton pseudonyme Minecraft et ton compte Discord. Les anciennes liaisons réalisées avant l’activation de cette fonctionnalité peuvent nécessiter une vérification manuelle.
